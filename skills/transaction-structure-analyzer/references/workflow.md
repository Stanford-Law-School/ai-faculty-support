# Workflow

1. Identify the transaction type, parties, document set, teaching or research purpose, and source status.
2. Map the transaction sequence and each document's role.
3. Identify consideration, conditions, approvals, deliverables, and timing dependencies.
4. Trace defined terms and cross-references before interpreting clauses.
5. Map representations, warranties, covenants, information rights, and governance rights.
6. Map breach consequences, indemnities, limitations, termination, and dispute provisions.
7. Identify which risks are allocated, shared, excluded, insured, or left unresolved.
8. Compare alternative structures only after identifying the purpose of the provision.
9. Surface assumptions and missing documents.
10. Produce a transaction architecture map, not party-specific advice.
