# Doctrine-Mapping Framework

Use four coordinated views:

1. **Authority hierarchy:** controlling, persuasive, historical, and secondary.
2. **Rule architecture:** rule, elements, tests, exceptions, burdens, defenses, remedies, and procedural prerequisites.
3. **Case relationships:** follows, distinguishes, limits, expands, criticizes, conflicts with, or overrules.
4. **Fact patterns:** facts that courts repeatedly treat as material.

Do not collapse a split into a single rule. Preserve competing formulations and identify which courts use each one.
