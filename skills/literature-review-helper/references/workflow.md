# Workflow

1. Define the review purpose, audience, disciplines, dates, languages, and source types.
2. Create search concepts, synonyms, controlled terms, and citation-chaining steps.
3. Select databases from the SLS guide based on coverage, not convenience.
4. Record every search, date, query, filter, and result count when available.
5. Screen sources using explicit criteria.
6. Build a source matrix from sources actually retrieved.
7. Synthesize themes, methods, disagreements, and limitations.
8. Label a possible gap as provisional until searches and source reading support it.
9. State coverage limits and next searches.
