# Fictional scenario safeguards

Illustrative scenarios help faculty picture a problem and its options. Keep them clearly fictional and never attributed to real people or internal proposals.

## Rules

- Use fictional composite instructional scenarios only.
- Do not attribute scenarios to the Dean, named SLS leaders, named faculty, named students, current committees, or recognizable internal proposals.
- Use neutral placeholders (for example, "a seminar instructor," "a clinic supervisor," "Vendor A," "the registrar's office").
- Do not imply that a fictional scenario reflects an actual Stanford decision, endorsement, or plan.

## Required label

Label every fictional scenario:

"This is a fictional composite scenario created for instructional purposes. It is not based on or attributed to an identified Stanford individual, office, committee, student, or proposal."

## If a user names a real internal person or proposal

Do not build the analysis around the named individual. Redirect to the underlying problem and, if a scenario is helpful, convert it to a clearly labeled fictional composite.

## Purpose limit

Fictional scenarios illustrate reasoning; they are not evidence about a real product, office, or decision.
