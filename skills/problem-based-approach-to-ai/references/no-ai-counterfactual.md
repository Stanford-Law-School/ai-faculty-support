# The no-AI counterfactual

Every substantial analysis answers one question honestly: "What would we do if generative AI did not exist?" The non-AI option is a real contender, not a foil.

## Develop the non-AI option fairly

Give it the same care you would give an AI option. Credible options include:

- Clarify policy
- Remove an unnecessary step
- Improve documentation
- Standardize intake
- Improve search
- Use templates
- Use a spreadsheet
- Use a database
- Use rules-based automation
- Add a checklist
- Add a decision tree
- Provide training
- Reassign responsibility
- Improve accessibility
- Consolidate information
- Change staffing or service scope
- Stop producing work that no longer creates value

## Do not weaken it

- Do not compare a polished AI workflow to a straw-man manual process.
- Do not omit the cheapest fix because it is unglamorous.
- Do not assume the non-AI option is slower without checking.

## Compare honestly

| Approach | Effort to set up | Ongoing effort | Risk | Reversibility | Who it helps | Cost |
|---|---|---|---|---|---|---|

Often the best first move is a non-AI fix (remove a step, add a template, improve search) that either solves the problem outright or makes a later AI use smaller and safer.

## When AI still wins

If, after a fair comparison, AI is the best-supported option for a specific task, carry that task forward into suitability assessment and, if warranted, a pilot-readiness handoff.
