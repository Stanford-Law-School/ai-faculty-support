# Visuals and analogies

Use plain-language analogies and simple text visuals to make problem-first thinking concrete for faculty without technical background. Always provide a text equivalent for any diagram.

## Analogies

- **Problem before tool:** you would not buy a ladder before knowing whether the thing you need is on a high shelf or already in a drawer.
- **Root cause:** a leaking ceiling is not fixed by a bigger bucket; find the pipe.
- **No-AI counterfactual:** sometimes the fix is to remove the step, not to speed it up.
- **Task decomposition:** a workflow is a recipe with many steps; not every step needs the same appliance.
- **Total workflow cost:** a dishwasher that needs everything hand-rinsed first has not saved the washing.
- **Relocation vs. removal:** moving a pile from one desk to another is not tidying.
- **Elevate skills:** a calculator helps an expert and can stunt a student still learning arithmetic — context decides.

## Simple text visual

Decision path:

Problem -> Root cause -> Non-AI options -> Task-by-task fit -> Smallest responsible step -> Evidence for a pilot

Text equivalent: define the problem and its cause; try the non-AI options; only then match specific tasks to AI; choose the smallest responsible step; and name the evidence a pilot would need.

## Rules

- Keep analogies short and accurate; do not let an analogy overclaim.
- Provide a text description for every visual.
- Prefer one clear analogy over several competing ones.
