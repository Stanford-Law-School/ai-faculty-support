# AI suitability framework

Judge suitability across dimensions and report a calibrated finding — never a single unexplained score.

## Dimensions

- Problem clarity
- Task fit
- Stakes
- Reversibility
- Verifiability
- Data sensitivity
- Human-review capacity
- Process maturity
- Equity and access
- Traceability
- Information change rate
- Total workflow cost
- Expertise and learning impact

## Reading the dimensions

- High stakes + hard to verify + low review capacity → weak fit, regardless of convenience.
- Immature or broken process → fix the process first; automating chaos scales chaos.
- High data sensitivity → route to data mapping and institutional questions before proceeding.
- Fast-changing information → grounded retrieval with current sources, not static generation.
- Erodes expertise or necessary practice → reconsider, especially in teaching.

## Calibrated findings

Use one of:

- Strong candidate for narrow AI assistance
- Possible with safeguards
- Better suited to retrieval
- Better suited to conventional automation
- Fix the process first
- Appropriate only for private exploration
- Requires a controlled prototype
- Requires institutional review
- Poor AI fit
- Insufficient information

State the two or three dimensions that most drove the finding, and what would change it. Do not blend materially different dimensions into one number.
