# Source Status and Verification Protocol

## Source-status ledger

Assign every material source one status:

- Supplied by the user
- Retrieved from an authoritative source
- Verified
- Located but not reviewed
- Secondary description only
- Model recollection requiring verification
- Illustrative or fictional
- Currentness not established

Never blur these categories.

## Proposition-to-authority chain

For every material legal proposition, record:

| Proposition | Authority | Jurisdiction | Date | Posture | Pinpoint | Treatment checked | Limitation |
|---|---|---|---|---|---|---|---|

A source is not support merely because it concerns the same topic.

## Mandatory distinctions

Always separate:

- Holding from dicta
- Court statement from party argument
- Allegation from finding
- Headnote from opinion text
- Binding from persuasive authority
- Primary authority from commentary
- Current law from historical law
- Majority from concurrence or dissent
- Rule from exception
- Quotation existence from proposition support
- Case outcome from broader doctrinal meaning
- Description from normative recommendation

## Current-law gate

Do not present a proposition as current law unless appropriate current authoritative sources and treatment have been checked. When that work has not occurred, say:

> This analysis identifies the relevant legal questions and likely source path, but current authority and treatment have not yet been verified.

Never claim citator validation unless an actual citator was used.
