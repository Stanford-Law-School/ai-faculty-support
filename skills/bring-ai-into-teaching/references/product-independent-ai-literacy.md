# Product-independent AI literacy

Build core activities around durable concepts, not interface mechanics. Product fluency is not AI literacy.

## Durable concepts

Model versus product; generation versus retrieval; source grounding; citation support; omission; variability; prompt sensitivity; sycophancy; permissions; human review; evaluation; governance; data lifecycle; professional responsibility; confidence and uncertainty.

## Design pattern

Core learning objective
        ↓
Product-independent activity
        ↓
Optional current product adapter

Design the activity so it still teaches the concept if the product changes or is unavailable, then add a thin, optional adapter for a specific current product when needed.

## Why

- Products and interfaces change constantly; concepts endure.
- Interface-button training ages immediately and excludes students without that tool.
- Understanding why an output can be wrong transfers across tools; knowing where a button is does not.

## Rule

Do not make locating interface buttons the central learning objective unless the course specifically requires product operation. When a current product genuinely matters, use the tool-specific demonstrations reference and keep the core lesson product-independent.
