# Empirical and data activities

For empirical legal studies and data work, use public or synthetic data and keep the analytical judgment with the student.

## Safe uses

Public datasets; synthetic datasets; extraction; classification; data cleaning; coding; exploratory analysis; chart interpretation; reproducibility checks; missing-data analysis; method critique.

## Students must distinguish

- Exploration from final analysis.
- Generated code from validated code.
- Pattern from causal claim.
- Output from evidence.
- Sample from population.
- Data access from ethical permission.

## Patterns

- Students critique AI-generated analysis code for errors before running it.
- Students compare an AI-suggested interpretation of a chart with what the data actually supports.
- Students identify where an AI summary overstates a correlation as causation.
- Students check reproducibility: does the same prompt/data yield the same result?

## Rules

- Prefer public or synthetic data; do not enter confidential or personal data.
- Require validation of any generated code before results are trusted.
- Teach that a fluent statistical narrative is not evidence; the data and method are.
- For formal empirical claims, recommend methodological consultation.

## Handoff

For representative testing of a data workflow, route to the Plan an AI Pilot; for evaluating a specific empirical claim, the Check an AI Claim.
