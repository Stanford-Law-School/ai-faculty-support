# Foundational work without AI

Protect the independent practice that builds the skill being taught. If AI performs the first step, the skill — and any mistake in it — can become invisible.

## Ask

- Which core skill is the activity intended to build?
- What must students attempt independently before using AI?
- What knowledge is necessary to evaluate AI output at all?
- What mistake would become invisible if AI performs the first step?
- Which difficulty is educationally useful?
- Which difficulty is merely administrative friction?

## Possible foundational work

Reading primary authority; identifying issues; briefing a case; developing an initial argument; selecting sources; creating search terms; drafting an issue list; analyzing facts; forming a prediction; identifying professional duties; producing a first reflection.

## The invisibility test

The danger is not that AI helps, but that it hides. If a student cannot evaluate an AI output because they never did the underlying reasoning, the activity has removed the learning. Sequence independent work first, then let AI critique, compare, or extend it.

## Rule

- Preserve difficulty when it serves the objective; remove friction that is merely administrative.
- Do not preserve difficulty just because it is traditional.
- The stronger the skill the course must build, the more foundational work should precede any AI use.
