# Workflow

1. Read the source scholarship or verified findings.
2. Identify audience, purpose, format, length, and desired action.
3. Identify the one central message and supporting evidence.
4. Preserve essential qualifications, source attribution, and uncertainty.
5. Translate terminology and structure without changing meaning.
6. Select examples that are accurate and appropriate.
7. Distinguish findings, interpretation, and recommendation.
8. Include a path to the full research and sources.
9. Check accessibility, tone, and headline accuracy.
