# Workflow

1. Identify the project stage, intended product, and audience.
2. Separate topic, problem, question, working claim, thesis, and contribution.
3. Build one bounded primary question and necessary subquestions.
4. Create a scope fence: included, excluded, and deferred.
5. Match the question to plausible methods and evidence.
6. Use the SLS database guide to identify likely source environments without claiming exhaustive coverage.
7. Identify access, confidentiality, expertise, and institutional constraints.
8. Create milestones and decision gates.
9. End with one concrete next research action.
