# Evaluation Index

- `plan-an-ai-pilot/`: regression scenarios for the Skill that turns a defined AI use case into a responsible, limited, documented pilot with a baseline, representative test set, predetermined criteria, omission and review-burden measurement, stop conditions, and a decision memo.
- `test-ai-governance/`: regression scenarios for the Skill that examines AI accountability, decision rights, human judgment, permissions, evidence gates, transparency, correction, monitoring, incidents, and stopping authority through fictional-composite simulations.
- `understand-an-ai-tool/`: regression scenarios for the Skill that researches and explains current AI products, features, models, and vendors.
- `bring-ai-into-teaching/`: regression scenarios for the Skill that translates AI understanding into purposeful teaching and learning activities with foundational non-AI work, visible reasoning, source verification, no-tool alternatives, accessibility, debriefs, and learning evidence.
- `problem-based-approach-to-ai/`: regression scenarios for the Skill that defines the real problem, compares AI and non-AI approaches, applies the SLS PAUSE framework, and produces a responsible use-case or no-use recommendation.
- `how-ai-systems-work/`: regression scenarios for the Skill that teaches AI-system layers, data flow, and ownership/control distinctions.
- `assessment-and-rubric-builder/`: evaluation area for the Skill that designs law-school assessments and rubrics.
- `class-session-planner/`: representative prompts and expected behaviors for the Skill that plans one class meeting or a short connected sequence.
- `course-and-syllabus-designer/`: evaluation area for the Skill that plans full courses and syllabi.
- `faculty-ai-policy-builder/`: evaluation area for the Skill that drafts course-level AI-use policies.
- `reading-list-and-course-materials-curator/`: evaluation area for the Skill that builds and verifies course reading lists.
- `socratic-question-and-hypothetical-designer/`: evaluation area for the Skill that designs Socratic questioning sequences and hypotheticals.
